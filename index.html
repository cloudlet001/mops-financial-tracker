📚 系統資料來源與 API 規格彙整

本系統所有金融股資料均直接取自官方公開管道，包含臺灣證券交易所 (TWSE) 與公開資訊觀測站 (MOPS)，並搭配 SQLite3 本地持久化快取。
🌐 公開資訊觀測站 (MOPS) ↗ 🌐 臺灣證券交易所 (TWSE) ↗ 🌐 TWSE Open Data 平台 ↗

▼ 🏛️ 四大核心來源總覽架構

① 公開資訊觀測站 (MOPS) 核心自結
• 全市場自結彙總表：當月金控/銀行自結營收、稅前淨利與 YoY。
• 歷史 1~12 月明細：歷年逐月單月/累計自結稅前損益。
• 發布週期：每月 1~10 號各金融機構自結公告時。
② 證交所盤後指標 (TWSE) 盤後行情
• 估值指標 (BWIBBU_d)：收盤價、殖利率 (%)、本益比 (PE)、PB。
• 收盤行情 (STOCK_DAY_ALL)：日成交股數 (換算成交張數)。
• 發布週期：每個台股營業日約 14:30~15:00 盤後結算。
③ 證交所 Open Data (OpenAPI) 財務與股利
• 除權除息公告 (t187ap45_L)：盈餘/法定公積/資本公積現金股利。
• 資產負債表 (t187ap07_L)：實收股本(億元)、每股淨值 (NAV)。
• 綜合損益表 (t187ap14_L)：官方正式公告基本每股盈餘 (EPS)。
④ 本地 / 雲端快取 (SQLite3) 毫秒讀取
• 資料庫檔案：mops_self_profit.db。
• 持久化快取：儲存清單、個股歷年損益與投資表指標。
• 雙模式支援：「資料庫優先」極速查詢與「強制重抓」即時更新。

▼ 📐 投資表核心指標計算與單位換算公式

  1. 普通股本 (億元)： 已發行普通股數 × 10元面額 / 100,000,000 = 已發行普通股數 / 10,000,000（換算為新台幣億元）。
    說明：資料取自 t187ap03_L 上市公司基本資料。系統已主動排除特別股股本，使股本與 EPS 換算完全符合普通股投資交易標準（例如 2881 富邦金普通股本精確為 1,400.74 億，排除 160 億特別股，與 XQ 完全一致）。
  2. EPS (X月自結)： 累計自結 EPS = X月累計自結稅前損益 (千元) / (普通股本 (億元) × 10,000)
    說明：自結獲利單位為千元（×1,000），普通股本 1 億元 = 10,000,000 股普通股，因此 千元 × 1,000 / 10,000,000 = 千元 / 10,000。若該月該檔股票尚未公布月自結，則統一顯示為 "-"。
  3. 成交量 (張)： STOCK_DAY_ALL 成交股數 / 1,000（換算為日成交張數）。
  4. 每股淨值 (元)： 優先採用資產負債表 每股參考淨值；若尚未公告時，則依據證交所公布之收盤價與 PB (股價淨值比) 反推計算：股價 / PB。
  5. 現金配息 (元)： 優先採用 t187ap45_L 最新股利年度之現金股利合計（盈餘分配 + 法定公積 + 資本公積）；若無資料時，則依證交所公布之 收盤價 × (殖利率 / 100) 反推計算。
  6. 本益比 (PE) & 現金殖利率 (%)： 直接採用臺灣證券交易所 (TWSE) 官方經盤後核算之最新數值 (BWIBBU_d)。
